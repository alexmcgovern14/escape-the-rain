# Favicon and Icon Files

The following image files need to be created and placed in the `app/` directory:

1. **favicon.ico** - Main favicon (should include 16x16, 32x32, 48x48 sizes)
   - Location: `app/favicon.ico`

2. **icon.png** - App icon (192x192 and 512x512 recommended)
   - Location: `app/icon.png` or `public/icon.png`

3. **apple-icon.png** - Apple touch icon for iOS (180x180)
   - Location: `app/apple-icon.png` or `public/apple-icon.png`

4. **opengraph-image.png** - Open Graph image for social sharing (1200x630px)
   - Location: `app/opengraph-image.png`

## Design Suggestions

- Use a simple icon representing rain/umbrella/weather
- Use the app's color scheme (blue theme: #2563eb)
- Ensure icons are clear and recognizable at small sizes
- Open Graph image should include app name and tagline
